# Learn Java

A Java RPG that teaches programming through exploration, debugging, coding challenges, and automated tests, where programming is _the tool_ that propels the game forward.  
This is a personal project, currently under development.

## Ideas for the game

The overall flow of the game is still in progress, but these are some initial ideas:

### Gather points and badges

Player -> completes Tasks -> completes Quests -> gather points -> score board and gets either badges or material to build something

### Solar punk farm rebuild

The player takes over an abandoned farm. They get to the house and there are lots of different old machines etc. that cannot be used, as well as an old computer. Through solving coding tasks, from basic to more advanced levels, the player can repair the machines and make them function again, buidling their home. In terms of design, the initial idea is for it to have a retro game vibe, in a farm/forest-setting with solar punk elements. TBD, but an idea is for there to be a board that holds the whole farm, where the user can move around. When they go up to an interactive object and choose to engage with it, they are moved to a storyline-page where there is explanations, task description and they solve the actual tasks.
To create a natural order and a feeling of progression and improvement, later tasks could depend on what you have already solved, either through their functionality, or through something it gives you. E.g. the solar panels can give electricity to get something else started, the mill could make flour for some project etc.

Initial ideas for tasks:

- A gate that must be unlocked through code, e.g. by fixing a missing piece of code, or simply getting the method to return true ("Make a method that opens the gate when the button is pressed.")
- There are solar panels on the main house, but they're not connected and working.
- Activate a broken mill by fixing broken code, either a bug such as a variable mismatch or broken logic, e.g. through if/else and a while-loop
- The player can make their own robotic pet through implementing a cat/dog interface, and creating their own pet
- As the game progresses more machinery and parts of the farm and surrounding area can be revealed, allowing me to continuously develop the game.
- To allow the user impact on the progression of the game, there could be a couple of forks in the story where the user can choose (e.g. through if/else) whether they want to go in one direction or other. TBD what exactly this could entail

### Detective bureau

There's a mystery, or maybe conspiracy, that the player needs to solve through solving programming tasks.
The tasks would start from elementary to more advanced Java. I want to explore this idea further, but to make a truly engaging mystery-game I feel the whole flow and storyline should be mapped out. I will therefore leave this idea to pursue at a later time.
